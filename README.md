# Taller5-Prolog4

Resolución del taller 5.

Que hice en este taller:

- **Nuevos personajes:** Se agregaron tres nuevos campeones al juego: Naruto, Natsu y Neo, cada uno con su respectivo nivel y cantidad de vida.

- **Inventarios nuevos:** Se añadieron inventarios para los nuevos personajes, incluyendo armas principales y objetos adicionales como pociones, escudos, amuletos y grimorios.

- **Armas con poder de ataque:** Se definieron armas con fuerza especifica de ataque para calcular el daño que puede realizar cada campeon durante un combate.

- **Enemigos escalados:** Se agregaron enemigos con diferentes niveles de dificultad y cantidad de vida: Duende, Hombre Lobo, Demonio y Rey Demonio.

- **Ataque individual:** Se implemento la ejecucion de ataques realizados por un solo campeon usando un arma de su inventario contra un unico enemigo.

- **Ataque en equipo:** Se implemento la posibilidad de que varios campeones ataquen juntos a un solo enemigo, sumando el poder de sus armas.

- **Validacion de inventario:** El sistema verifica que cada campeon realmente tenga el arma que intenta usar antes de ejecutar el ataque.

- **Resultado del combate:** El sistema compara el poder total del ataque con la vida del enemigo para determinar si gana el campeon, ganan los campeones o ganan los malvados.

- **Mensajes automaticos:** Se generan mensajes segun el resultado del combate, mostrando el poder total, la suma de poderes y la vida restante del enemigo cuando sobrevive.
